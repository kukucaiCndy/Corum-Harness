**应用版本 `0.7.0`** · 底座 DeepSeek Harness `0.1.5-rc.3`

## TOP5 更新日志

1. **Windows · 修「清完 C 盘后应用起不来、凭证全失效」**（本版最重要）：应用的用户数据目录原先放在系统临时目录（`%LOCALAPPDATA%\Temp`）里，而 Windows 的加密密钥（供保存 API Key 使用）就存在该目录的 `Local State` 文件中。用清理软件清 C 盘会把整个临时目录删掉，于是下次启动应用拿到一把全新的密钥，之前保存的所有 API Key 再也解不开，启动时直接失败、界面只剩「后台启动失败：进程提前退出（code 1）」，点「重试启动」永远无效。

   本版把用户数据目录移到**每用户的持久目录**（`%APPDATA%`），并在升级后的首次启动时把旧目录里的密钥文件迁移过来，使已保存的 API Key **继续可用**。macOS / Linux 的落点也一并移出临时目录（它们的密钥本就在系统钥匙串 / 密钥环里，不受此问题影响）。

2. **Windows · 内置 VC++ 运行库**：安装包内自带 VC++ 运行库，启动时检测到缺失即静默安装，不再出现「缺少 vcruntime140.dll」导致应用打不开。

3. **编排 · 移除 script 模式**：编排只保留声明式 tasks，去掉了容易误用的 script 模式。

4. **Windows · 8.3 短名工作区**：工作区路径是 8.3 短名时，改动不再被误判成「工作区外」。

5. **编辑器 · 主题与显示偏好**：对齐主题配色，并启用显示项偏好设置。

## 注意事项

- **升级后 API Key 会保留**：从 0.6.0 及更早版本升级时，首次启动会自动迁移密钥文件，已保存的 API Key 无需重新录入。若你的机器此前已经被清理工具删过临时目录（即已经出现过「code 1」启动失败），那批凭证在主密钥重建时已不可恢复，仍需**重新录入 API Key**；本版只是防止它再次发生。
- **Windows 资产未签名**：首次运行安装器会被 SmartScreen 拦截 —— 点「更多信息」→「仍要运行」即可。这是预期行为，不是病毒告警。
- **Windows / Linux 暂无托盘**：关闭主窗口即退出应用（托盘仅在 macOS 提供）。macOS 关窗为隐藏到菜单栏。
- **Windows 按用户安装**：默认装到当前用户目录，不需要管理员权限。
- **Linux 迁移行为未实测**：本版的三平台门禁覆盖 macOS 与 Windows 真机；Linux 侧的用户数据目录迁移按机制判定为「无需迁移」（密钥在密钥环），但未在 Linux 真机上验证过。
