## ⚠️ 安装前必读（Windows）

- **未签名**：本 release 未做代码签名。首次运行安装器会被 SmartScreen 拦截——
  点「更多信息」→「仍要运行」即可；这是预期行为，不是病毒告警。
- **按用户安装**：默认装到当前用户目录（`perMachine: false`），不需要管理员权限
  （`requestedExecutionLevel: asInvoker`）；换过安装目录后重装会记住上次路径。
- **许可协议**：安装向导内展示 `LICENSE`（Apache-2.0）全文，继续安装即表示接受。

## Windows 差异（与 macOS 版）

- 托盘：Windows 暂无托盘实现，**关窗即退出**（见 `src/electron/platform/win32.ts` 能力表 `tray: false`）。
- 终端：按 `pwsh → powershell → cmd` 顺序探测可用 shell。
- 凭据：走 Windows DPAPI（`secretStore: 'dpapi'`），无需 `password-store` 开关；
  重装系统/换用户后旧凭据不可解密，需重新填 Key。
- 路径分隔符：`\\`；工作区、`.corum` home（默认 `%USERPROFILE%\.corum`）均按平台语义解析。

## 从源码构建（必须在 Windows 主机上）

原生依赖（`node-pty`、`koffi` 等）是平台相关的：**必须在 Windows 本机 `pnpm install`，
交叉打包不通**（Linux 场的同款教训同样适用于 Windows）。

```cmd
pnpm install
pnpm pack:win
```

完整四步（`packages/desktop/scripts/pack.mjs win32` 自动串起）：

1. `build`（`tsc -b` + `tsdown` + `inline-monaco-css.mjs`，`CORUM_TARGET_PLATFORM=win32` 烘入产物）
2. `pack:host:win`（物化 Windows 版 host 闭包；显式 `--platform=win32 --arch=x64`，绝不从构建机推断）
3. `pack:node:win`（下载 Windows 版 Node 运行时，`node-v*-win-x64.zip`）
4. `pack:app:win`（`electron-builder --win --x64` 出 NSIS + zip）

前置守卫：`scripts/electron-pin.json` 必须先有 `win32-x64` 的二进制身份记录
（`node scripts/verify-electron-pin.mjs --record` 在一次已知良好的 Windows 构建上采集），
否则打包链硬失败——这是 macOS 钥匙串事故换来的机制，不要绕过。
