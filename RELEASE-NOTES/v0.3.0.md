## TOP5 更新日志

1. **Windows**：桌面端**首次随版本正式发布**（NSIS 安装向导 + 免安装 zip）。含两个阻断级缺陷的修复——交叉打出的包**白屏起不来**（平台上专属原生依赖按命名规律整体校正 + 产物启动硬门禁）、**新建工作区 exit 128**（git 属主 `safe.directory`）；并让 git/node 子进程不再弹出控制台黑框。

2. **预设模块**：Agent 预设模块化落地——**导入向导 + 发布流程**。把一个 Agent 连它引用的技能与 MCP 依赖收成一个自洽目录，可以导出给别人安装，不再出现「拷个 `agent.json` 过去，技能和 MCP 全不存在」。

3. **MCP**：修「服务配了 `guidance` 就让**整个 preset 挂载失败**、Agent 完全打不开」（issue #3）。根因是守卫读了未 `inject` 的服务属性、抛错发生在 `try/catch` 之外。

4. **提交卡片**：卡片改挂**会话流**（不再悬停输入框上方）；且卡片出现后的**提交过程（思考 / 工具调用 / 结论）收进卡片内部**，默认收起、点头部才展开。

5. **三处可见缺陷**：子 Agent 模型下拉**选供应商不再回弹「未设置」**；有工作区但无会话时侧栏正确显示工作区分组（不再误进空态）；「新建任务」的工作区下拉恢复首项「打开本地文件夹」。

## 注意事项

- **Windows 资产未签名**：首次运行安装器会被 SmartScreen 拦截 —— 点「更多信息」→「仍要运行」即可。这是预期行为，不是病毒告警。
- **Windows / Linux 暂无托盘**：关闭主窗口即退出应用（托盘仅在 macOS 提供）。macOS 关窗为隐藏到菜单栏。
- **Windows 按用户安装**：默认装到当前用户目录（`perMachine: false`），不需要管理员权限；换过安装目录后重装会记住上次路径。
- （开发）`@deepseek-ai/dsh-client-ui-primitives` **无法用 `pnpm patch` 修** —— 补丁会**静默无效**。
- （开发）给一个已有容器加 `backdrop-filter`（或 `will-change: transform`）会把**它内部每一个 `position: fixed` 浮层**从「相对视口」改成「相对该容器」—— 这是跨组件的**静默语义变更**：改的是 A（玻璃皮肤），坏的是 B（提示气泡 / 下拉 / 悬浮卡），而 B 一行没动。
- （开发）`saveProfile` RPC 会**静默丢掉**任何不在 `SaveProfileInput` 白名单里的 profile 字段 —— 新增字段时必须同步白名单。
