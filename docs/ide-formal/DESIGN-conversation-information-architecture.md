# 会话区信息架构与交互模型（重设计 · 方向稿）

> 状态：**方向已确认（2026-08-29）** · 下一步 Pencil 逐卡画定稿
> 这是「重新全部设计」的第一份方向稿：先对齐**信息架构**（AI 回复过程的瀑布流模型 +
> 统一收尾 + 工具聚合），确认后再到 Pencil 逐卡画定稿。
> 依据：你的想法（ai 不包卡/瀑布流/统一收尾）+ 官方 turn 数据模型 + corum 液态玻璃语言。

---

## 0. 一句话模型

**一轮对话 = 一条「过程瀑布」+ 一次「统一收尾」。**
AI 回复不再是「一张封闭的对话框」，而是：以 avatar 开头，过程中的各种内容
（思考、文字、工具、子 Agent、文件变更）作为**独立的、形态各异的卡片**依次流出；
等 Agent 这一轮做完总结，**最后在末尾统一出现一行操作**（分叉 / 点赞 / 复制 / 耗时 / 重试）。

这与官方 turn 数据模型天然对齐（assistant-step 过程块 + turn-tail 统一 actions），
所以 B 方案复用官方数据流正好承载它。

## 1. 消息流的信息层级（三类主体，三种视觉权重）

| 主体 | 视觉权重 | 形态 | 说明 |
|---|---|---|---|
| **You（用户）** | 强 | **品牌实底气泡**（靠右） | 唯一的「气泡」，右下小角，明确「我说的」 |
| **过程（Agent 工作中）** | 中～弱 | **轻量内容流**（不包大卡） | 思考/文字/工具/子Agent 依次流出，层次分明但不喧宾夺主 |
| **收尾（一轮完成）** | 弱 | **一行轻操作**（不包卡） | fork/点赞/复制/耗时/重试，hover 才明显，平时低调 |

**核心原则：减少「框」。** 现在的毛病是每条内容都套一张玻璃卡，满屏是框。
新设计里——只有「需要强调、可交互、有边界语义」的内容才用卡（审批卡、工具聚合卡、
Review 卡、子 Agent 卡、文件变更卡）；纯文字叙述（思考、回复正文）**不包卡**，
用排版（缩进/间距/颜色层级）区分，让长对话有呼吸感。

---

## 2. AI 回复过程瀑布（assistant-step 的视觉分解）

一轮 AI 回复 = 一个「过程块序列」。每块是一个独立内容单元，按类型给不同形态：

```
● Corum Agent                              ← 轮头：avatar + 名（仅一轮一次，不是每张卡都重复）
│
├─ ▸ 思考过程（reasoning）                   ← 默认收起的一行摘要，点开展开；弱化（label-tertiary）
│
├─ 回复正文第一段（text）                    ← 裸 markdown 流，不包卡，正常正文排版
│
├─ [工具聚合卡] 运行了 3 个工具 ▸             ← 一轮里的所有工具调用聚成一张可展开卡（见 §3）
│
├─ 回复正文第二段（text）                    ← 继续裸 markdown 流
│
├─ [子 Agent 卡]（若有）                     ← subagent 任务进度卡（独立卡，见 §5）
│
└─ 回复正文最后一段（text / 总结）           ← 收尾的总结正文，裸流
```

**轮头（avatar + 名）**：一轮 AI 回复**只在开头出现一次**（avatar + 「Corum Agent」），
后续过程块**不再重复头部**——这是与现在「每张 ai 卡都带头像+名+时间」的关键区别。
回复时间在轮头右侧，弱色。

**正文（text）**：不包卡，就是干净的文章排版（标题/列表/代码块照 markdown），
代码块自带 glass-2 浅底 + 复制钮（hover 显）。

## 3. 工具聚合卡（turn-process 的形态）

**一轮里的所有工具调用聚成一张卡**，默认收起：

```
┌──────────────────────────────────────────┐
│ ⚙ 运行了 3 个工具              ▸  12.4s  │
└──────────────────────────────────────────┘
        展开后 ↓
┌──────────────────────────────────────────┐
│ ⚙ 运行了 3 个工具              ▾  12.4s  │
│  ─────────────────────────────────────   │
│  ● bash · pwd                      ✓ 0.1s│
│  ● read · package.json             ✓ 0.2s│
│  ● edit · src/index.ts             ✗ 1.9s│
└──────────────────────────────────────────┘
```

- **收起态**：一行摘要（图标 + 「运行了 N 个工具」+ 展开 chevron + 总耗时）。glass-2 浅卡。
- **展开态**：列出每条工具（状态点 ✓/✗/⟳ + 工具名 · 主参数 + 单条耗时）。
- **运行中**：收起态图标 pulse，文案「正在运行 <当前工具名>…」。
- 一张卡 r12 glass-2，不再每个工具一张卡。

---

## 4. 统一收尾（turn-tail 的形态）

一轮 AI 总结完成后，末尾出现**一行轻操作**（不包卡，平时低调，hover 提亮）：

```
   ⑂ 分叉   ♥ 赞   ⧉ 复制   ⟳ 重试        耗时 18.7s
```

- 内容：**分叉 / 点赞 / 复制 / 重试** + 右侧 **耗时**（弱色）。
- 形态：一行小图标钮（26×26 ghost），不包卡，不喧宾夺主。
- 时机：**只在一轮完成（turn-end）后出现**，过程中不出现。
- 「点赞」是新增的反馈入口（message-feedback，官方有此机制可接）。

---

## 5. 其它卡片的归属（保留为「卡」的内容）

以下**保留卡片形态**（有边界/交互/强调语义），按现有设计语言细化：

| 卡 | 形态 | 说明 |
|---|---|---|
| **审批卡** | glass-1 + warn 描边 r18 | 拆分按钮（允许一次+▾ 浮层 menu）+ 拒绝；出现在过程瀑布中（它就是要打断等待的） |
| **子 Agent 卡** | glass-1 r14 | 子 Agent 任务进度（avatar/名/任务/run-chip/进度条/步骤）；在瀑布中流出 |
| **Review 卡** | glass-1 r14 | 文件更改审查，固定对话区底部（不在瀑布内）；折叠/全部撤销/全部保留 |
| **错误卡** | glass-1 + error 描边 | turn-error，错误摘要 + 重试 |
| **命令卡 / 上下文引用卡** | glass-2 r12 | /命令、@引用 的轻卡 |
| **边界卡**（compaction） | 无卡，一行分隔标记 | 压缩边界用一条淡分隔线 + 小字，不用卡 |

## 6. 输入区 / 头部 / 统计（骨架，沿用官方能力 + corum 样式）

- **Convo Header**：对话/轨迹选项卡（左）+ spacer + 分叉/统计/关闭（右，30×30 hbtn）。
- **Chat Input**：官方 composer 能力（@上下文芯片、/命令、附件、queue、stop、模型座位
  复用 corum-ui-model-selection），样式按 corum 玻璃语言重做（上行输入区 + 下行工具条）。
- **统计**：点统计 hbtn 弹 popup-status 浮层（轮次/时长/token/费用）；不在全局状态栏。
- **空态**：hero 品牌 + 引导（复用官方 hero 槽，样式 corum 化）。
- **弹层**：popup-status / popup-context-usage / popup-context(＋) / popup-permission(🛡)
  / popup-agent(@)——沿用 DESIGN §6.2，重设计定稿。

## 7. 视觉/动效基调（液态玻璃）

- **框的消减**：只有 §5 列的卡用玻璃卡；正文/思考用排版层级（缩进 + 颜色）不包卡。
- **过程块的节奏**：块间距 6-8px，思考/弱化内容用 label-tertiary，正文 label-primary。
- **进入动效**：过程块 translateY(8px→0) 200ms 交错 30ms；流式打字机光标 530ms；
  工具聚合卡展开高度 auto 280ms + chevron 旋转；统一收尾行 fade-in 200ms。
- **玻璃质感**：保留背景环境光斑；卡片 glass-1/2 + 光边；少用硬阴影。

## 8. 方向点（2026-08-29 已全部确认）

1. **减框**：正文/思考**裸流不包卡**（排版分层）；只有审批/工具聚合/子Agent/Review/错误等
   强调/可交互内容用卡。✓
2. **轮头**：主 Agent 一轮一次；子 Agent 用自己的子 Agent 卡区分。✓
3. **收尾按钮集**：分叉 / 点赞 / 复制 / 重试 + 耗时。✓
4. **工具聚合卡**：默认收起一行摘要（运行了 N 个工具 ▸），点开看明细。✓
5. **reasoning**：默认收起一行摘要，点开展开。✓
6. **审批卡位置**：就地插入过程瀑布（它出现的位置，打断处）。✓
